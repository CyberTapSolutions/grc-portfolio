# Cybersecurity GRC Portfolio

Cybersecurity Governance, Risk, and Compliance portfolio demonstrating hands-on experience with risk assessment, control evaluation, compliance mapping, identity and access management, third-party risk, and cybersecurity posture management.

This portfolio was developed to demonstrate how cybersecurity risks can be identified, assessed, documented, communicated, and treated using practical GRC methodologies and recognized cybersecurity frameworks.

## Risk Methodology

Several portfolio projects use a simplified **5 × 5 cybersecurity risk matrix**:

**Risk Score = Likelihood × Impact**

| Score | Rating |
| ---: | --- |
| 1–4 | Low |
| 5–9 | Medium |
| 10–16 | High |
| 17–25 | Critical |

Risk assessments consider both **inherent risk** and **residual risk** after security controls are applied.
